# Bakersoft

Web del estudio, publicada con GitHub Pages en https://baker-software-studio.github.io

| Ruta | Contenido |
| --- | --- |
| `index.html` | Inicio, con una sección por app |
| `crimeoku/privacy/` | Política de privacidad de Crimeoku (la URL que va en Play Console) |
| `app-ads.txt` | Verificación de AdMob (completar con la línea que da AdMob) |
| `style.css`, `lang.js` | Estilos compartidos e idioma (español o inglés según el dispositivo) |
| `img/` | Imágenes de las apps |

Sitio estático, sin build: se edita el HTML y se pushea a `main`.
